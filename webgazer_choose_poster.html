How to Use

  1. Pick a poster from the dropdown (or search by name).
  2. Click Start and allow webcam access.
  3. Click each orange calibration dot, then each blue accuracy dot.
  4. Look at the poster — recording begins automatically.
  5. Click Stop, then Download CSV for analysis.
Run the Python analyzer with --gaze-file your_export.csv to compute PES scores and attention heatmaps.
